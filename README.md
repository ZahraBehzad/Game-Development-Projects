# Game Development Projects

Unity projects built as part of my **Game Development** course. Each folder is a self-contained Unity project covering a different set of gameplay systems, from early 3D prototyping to a fully playable 2D puzzle game.

## Projects

| Project | Type | Description |
|---|---|---|
| [`Little_Farmer_Colt`](./Little_Farmer_Colt) | 3D, in-progress | A farm-life prototype built during the course — terrain, animals, and basic farming mechanics. |
| [`Tetris`](./Tetris) | 2D, final project | A complete, fully playable Tetris clone with rotation, ghost pieces, and line clearing. Presented to the course instructor as the final project. |

## Requirements

- **Unity Editor 2022.1.24f1** (or a compatible version)
- A C# IDE such as Visual Studio or VS Code with the Unity extension

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/Game-Development-Projects.git
   ```
2. Open **Unity Hub** → **Add project** → select either `Little_Farmer_Colt` or `Tetris`.
3. Let Unity import the project, then press **Play** in the Editor.

See each project's own README for details on controls and current status.
